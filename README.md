# Student Career Preference Analysis

## Government vs Private Employment Preferences

### Project Overview

This project analyzes students' career preferences between government and private employment using Python, SQL, Power BI, and Excel.

The dataset contains 1,000 synthetic student records created for learning and portfolio purposes.

### Project Objectives

- Analyze student career preferences.
- Compare government and private employment preferences.
- Explore expected salary.
- Analyze government exam preparation.
- Identify preferred skills.
- Compare career preferences across degree categories.
- Develop practical data analytics skills.

### Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL (SQLite)
- Power BI
- Microsoft Excel
- Git and GitHub

### Dataset Information

The dataset contains 1,000 student records with information about education, career preferences, salary expectations, skills, and employment preferences.
